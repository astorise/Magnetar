# ModernBERT encoder graph fixture

`modernbert-encoder-reference.json` is copied from the ModernBERT component's
synthetic f32 fixture. Its generator executes pinned Transformers 5.23.0
embeddings, rotary positions and encoder layers with PyTorch 2.15; the exact
source digest and regeneration command are in
`components/modernbert/tests/fixtures/README.md`. It covers three layers,
global/local windows, padding, explicit positions and both bias forms. No
checkpoint weights are included. The runtime graph test reconstructs the
same synthetic weights and compares the encoder output.

`gelu-exact-reference.json` is generated by
`generate-gelu-exact-reference.py` from PyTorch 2.15's erf-defined f32 GELU.
The corresponding test checks 197 points spanning -12 through 12 to an
absolute tolerance of 5e-7. No input data from a checkpoint is included.
